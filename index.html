MyDayDiary Privacy Policy

Last updated: May 2026

MyDayDiary is a local-first personal journaling application designed to help users privately store diary entries, memories, places, people, and personal reflections.

Data Storage

MyDayDiary stores user content locally on the user's device. The application does not require a user account and does not upload diary content to external servers operated by MyDayDiary.

Stored content may include:

  • diary entries
  • text notes
  • photos selected by the user
  • people and place references
  • emotional tags
  • local application settings

Permissions

The app may request access to:

  • Photos/Media: for attaching images to entries
  • Microphone: for optional speech-to-text input
  • Device security/biometrics: for notebook protection and privacy features

Permissions are only used for the corresponding in-app functionality.

Purchases

Premium features are processed through Google Play Billing. MyDayDiary does not directly process or store payment information.

Data Sharing

MyDayDiary does not sell user data and does not share diary content with third parties.

Backups and Exports

Users may export backups or PDF files from the app. Exported files are under the user's control and should be stored securely.

Security

MyDayDiary includes local privacy and security features such as:

  • encrypted local database storage
  • encrypted backups
  • optional screenshot protection
  • optional notebook/device-lock protection
  • EXIF metadata stripping for imported images

No software can guarantee absolute security.

Data Deletion

Users can permanently delete notebooks, entries, and application data directly within the app.
