MyDayDiary Privacy Policy

Last updated: May 2026

MyDayDiary is a local-first personal journaling application designed to help users privately store diary entries, memories, places, people, and personal reflections.

Data Storage

MyDayDiary stores user content locally on the user's device. The application does not require a user account and does not upload diary content to external servers operated by MyDayDiary.

Stored content may include:

  • diary entries
  • text notes
  • photos selected by the user
  • people and place references
  • emotional tags
  • local application settings

Permissions

The app may request access to:

  • Photos/Media: for attaching images to entries
  • Microphone: for optional speech-to-text input
  • Device security/biometrics: for notebook protection and privacy features

Permissions are only used for the corresponding in-app functionality.

Purchases

Premium features are processed through Google Play Billing. MyDayDiary does not directly process or store payment information.

Data Sharing

MyDayDiary does not sell user data and does not share diary content with third parties.

Backups and Exports

Users may export backups or PDF files from the app. Exported files are under the user's control and should be stored securely.

Security

MyDayDiary includes local privacy and security features such as:

  • encrypted local database storage
  • encrypted backups
  • optional screenshot protection
  • optional notebook/device-lock protection
  • EXIF metadata stripping for imported images

No software can guarantee absolute security.

Data Deletion

Users can permanently delete notebooks, entries, memories, and application data directly within the app.

Because MyDayDiary does not use user accounts or cloud storage, deleting local app data or uninstalling the application removes stored data from the device.

Exported backup or PDF files created by the user are not automatically deleted and remain under the user's control.

AntiNotes Privacy Policy

Last updated: May 2026

AntiNotes is a local-first thought stream application designed to help users privately capture temporary thoughts, text notes, images, and audio attachments.

Data Storage

AntiNotes stores user content locally on the user's device. The application does not require a user account and does not upload user content to external servers operated by AntiNotes or Low Noise Works.

Stored content may include:

  • thoughts and text notes created by the user
  • images selected or captured by the user
  • audio recordings created by the user
  • creation, edit, visit, vitality, and archive/echo state metadata
  • local application settings, including theme preferences

Permissions

The app may request access to:

  • Photos/Media or image picker access: for attaching images to thoughts
  • Camera: for capturing images to attach to thoughts, if the user chooses this action
  • Microphone: for recording audio attachments
  • Files or document access: for local export and import selected by the user

Permissions are only used for the corresponding in-app functionality and only after the user chooses to use that feature.

Data Sharing

AntiNotes does not sell user data and does not share user thoughts, images, audio recordings, or app content with third parties.

Backups, Exports, and Imports

Users may export or import local backup files. Exported files are created under the user's control and should be stored securely.

Exported files may contain user-created content and metadata. If media export is supported, exported backup files may also include images or audio recordings attached by the user.

Security

AntiNotes is designed as a local-first application. User content remains on the device unless the user manually exports or shares it.

No software can guarantee absolute security. Users should protect their device and exported files appropriately.

Data Deletion

Users can delete thoughts and associated local content within the app.

Because AntiNotes does not use user accounts or cloud storage, deleting local app data or uninstalling the application removes stored app data from the device.

Exported files created by the user are not automatically deleted and remain under the user's control.

Children's Privacy

AntiNotes is not designed to knowingly collect personal information from children. The app does not require accounts and does not operate a server-side user database.

Contact

For privacy-related questions, contact: Low Noise Works
